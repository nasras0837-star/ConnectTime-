# ConnectTime Free Radio & Music

The `/radio` page provides a region/country/language/genre-searchable radio directory with HTML audio playback, favorites, station homepages, and direct stream links. It uses the community Radio Browser API through a server-side proxy at `/api/radio`; no API key is required.

## Coverage

The UI includes country-code groupings for Africa, Asia, Europe, North America, South America, and Oceania. A global search can retrieve stations beyond these groups. Radio Browser's catalog is community-submitted and changes continuously; no directory can guarantee a station exists for every country, or that every stream is active or licensed for every listener.

## Free music discovery

The page also links to artist and catalog platforms (Jamendo, SoundCloud, Bandcamp, and Free Music Archive). “Free” varies by release, account, territory, and license. ConnectTime does not download, host, or re-broadcast their music.

## Limitations and safety

- Stations are third-party streams and may include advertising, mature content, unreliable links, or location restrictions.
- Station metadata is user-contributed; users should report inaccurate or unsafe listings.
- Favorite stations currently persist in browser state only (not cross-device or account-synced).
- No user uploads, recording, stream relay, or paid audio service is implemented.
- Respect copyright, broadcaster terms, and country-specific rules. ConnectTime does not circumvent geo-restrictions.
